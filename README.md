# Optimal Industrial Scheduling in Day-Ahead Electricity Markets

This repository contains the Python source code, mathematical formulations and datasets developed for my Integrated Master's Thesis: **"Optimal Operation of Industrial Units via Active Participation in Short-Term Electricity Markets"** (Department of Electrical and Computer Engineering, University of the Peloponnese).

## Overview
This project formulates a Mixed-Integer Linear Programming (MILP) model based on Two-Stage Stochastic Programming to solve the joint Order Acceptance and Scheduling (OAS) problem under uncertainty. It aims to minimize energy costs via Demand Response (DR) mechanisms and maximize overall profit by dynamically adapting to price volatility in the Day-Ahead Market.

## Repository Structure

### Main Optimization Models
* `deterministic_problem_code.py`: Implementation of the baseline deterministic MILP model.
* `stochastic_problem_code.py`: Implementation of the Two-Stage Stochastic MILP model using scenario trees.

### Stochastic Metrics & Evaluation
The repository includes isolated scripts for calculating standard stochastic programming metrics to quantify the value of explicit uncertainty management:
* `ws_calculation.py`: Wait-and-See (WS) approach calculation.
* `ev_calculation.py`: Expected Value (EV) calculation.
* `eev_calculation.py`: Expected result of using the EV solution (EEV).
* `vss_calculation.py`: Value of the Stochastic Solution (VSS).
* `evpi_calculation.py`: Expected Value of Perfect Information (EVPI).
* `performance_metrics.py`: Aggregation of operational results and final system performance evaluation.

### Data & Preprocessing
* `data_clustering.py`: Script that applies **K-Means clustering** to historical market data to generate representative scenario trees and calculate their occurrence probabilities.
* `hourly_electricity_prices_GR.xlsx`: Historical Day-Ahead Market prices for the Greek bidding zone.
* `deterministic_data.xlsx` & `stochastic_data.xlsx`: Input parameters, factory configurations, and order sets for the respective models.

### Results & Exports
* `deterministic_problem.lp` & `stochastic_problem.lp`: Exported Linear Programming files containing the explicit mathematical constraints, variables, and objective functions generated by the solver.
* `deterministic_results/` & `stochastic_results/`: Output directories for generated production schedules, consumption profiles, and economic reports.
